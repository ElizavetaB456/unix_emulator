# Эмулятор командной строки UNIX-подобной ОС - вариант 3

Учебный CLI-эмулятор, развиваемый по пяти этапам. Виртуальная файловая
система хранится в памяти; исходные данные загружаются из CSV, физические
файлы VFS не распаковываются и не изменяются.

## Возможности по этапам

1. **REPL:** приглашение `username@hostname:~$`, раскрытие переменных
   окружения (`$HOME`), разбор аргументов с кавычками, заглушки `ls` и `cd`,
   команда `exit` и сообщения об ошибках.
2. **Конфигурация:** параметры `--vfs`, `--prompt`, `--script`; вывод
   параметров командой `conf-dump`; скрипт останавливается при первой ошибке.
3. **VFS:** загрузка дерева файлов и каталогов из CSV в память.
4. **Основные команды:** `ls`, `cd`, `history`, `cal`, `who`.
5. **Дополнительные команды:** `mkdir`, `mv`; изменения выполняются только
   во внутреннем представлении VFS и не записываются обратно в CSV.

## Структура

- `src/stage1.py` … `src/stage5.py` — реализации пяти этапов.
- `tests/` — pytest-тесты для этапов.
- `examples/vfs_minimal.csv`, `vfs_many.csv`, `vfs_deep.csv` — VFS разного
  размера и вложенности.
- `examples/startup_stage*.sh` — стартовые скрипты эмулятора.
- `run.sh`, `run.bat` — запуск эмулятора в Unix-подобной оболочке и Windows.
- `scripts/test_vfs.sh`, `scripts/test_vfs.bat` — проверка вариантов VFS.
- `scripts/test_stages.sh` — shell-сценарий проверки этапов.
- `Makefile`, `.gitignore`, `requirements.txt` — сборка, игнорирование
  артефактов и тестовая зависимость.
